# Bug Tracking

Bugs found during development and testing are tracked in GitHub Issues. Each
report includes steps to reproduce, expected results, and actual results. A
handler is assigned to resolve the issue, then documents the cause and fix for
future reference.

# Adding a bug/suggestion report
Go to https://github.com/juvs227/wee-sports/issues to add an issue. 
Assign labels to classify the issue:
- accessibility — Barrier affecting people with disabilities
- bug — Something isn't working
- documentation — Improvements or additions to documentation
- duplicate — This issue or pull request already exists
- enhancement — New feature or request
- good first issue — Good for newcomers
- help wanted — Extra attention is needed
- invalid — This doesn't seem right
- question — Further information is requested
- user-study — No description provided
- wontfix — This will not be worked on
A recommended flow is to summaries the issue in the title, mentions expected and actual behaviour, and possibly direction of fixing it.
